# VTS Demo

A demonstration project showcasing VTS (Video Tracking System) capabilities.

## Overview

This repository contains a demo implementation of a Video Tracking System with core features for video processing and object tracking.

## Features

- 🎬 Video processing capabilities
- 📍 Object tracking
- 🔧 Modular architecture
- 📊 Demo implementations

## Getting Started

### Prerequisites

- Python 3.7+
- Required dependencies (see requirements.txt)

### Installation

```bash
git clone https://github.com/ajaykokate28/VTS-Demo.git
cd VTS-Demo
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```
